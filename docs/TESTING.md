# 實機驗收測試清單（Windows 11 + Outlook 2007）

目標機器：**Windows 11 + Outlook 2007（32 位元）**。每項通過打 ✓，失敗記錄畫面／訊息。

## 0. 前置條件

- [ ] Windows 11 已安裝 .NET Framework 4.8（安裝程式會檢查；也可先到 `設定 → 應用程式 → 選擇性功能` 確認）
- [ ] Outlook 2007 可正常開啟、可收發信
- [ ] 準備一個「測試用 PST」：可從 Outlook「檔案 → 資料檔管理 → 新增」建立一個新的 .pst，丟幾封測試信進去（含中文主旨與內文，例如「王小明 訂單編號 20240105」）
- [ ] 準備幾個已知搜尋字串：公司名（2 字，如「鴻海」）、人名（3 字，如「王小明」）、詞組（4 字，如「訂單編號」）、英文單字（如 order）

## 1. 安裝

- [ ] 執行 `PstSearchTool-Setup-1.0.0.exe`，安裝完成後可從開始功能表／桌面捷徑開啟
- [ ] 程式開啟後主視窗正常顯示（無錯誤對話框）
- [ ] 狀態列顯示「已索引 0 封郵件」

## 2. 目前 PST 模式

- [ ] 「目前 Outlook 中的 PST」已勾選；重新整理來源後列出 Outlook 內存放區（主要信箱應自動勾選）
- [ ] 點選存放區，左側資料夾樹正確載入（收件匣／寄件匣／子資料夾…）
- [ ] 按「收件匣」快速按鈕 → 僅收件匣被勾選；按「寄件匣」→ 僅寄件匣；「全選／清空」正常

## 3. 建立索引

- [ ] 勾選收件匣＋寄件匣，按「建立/更新索引」，進度列與狀態正常跑動
- [ ] 索引完成後狀態顯示「索引完成，共 N 封」；N 與 Outlook 內郵件數一致（可抽查）
- [ ] **再次按「建立/更新索引」**：未變更資料夾應顯示「未變更，略過」，幾秒內完成（增量驗證）
- [ ] 在 Outlook 收一封新信後，再次索引 → 只重建該資料夾、新信被納入

## 4. 搜尋

- [ ] 搜尋 3 字人名「王小明」→ 找到含該字串的信件，結果依日期排序
- [ ] 搜尋 **2 字公司名「鴻海」** → 找到（驗證 2 字元中文支援）
- [ ] 搜尋 4 字詞「訂單編號」→ 找到
- [ ] 搜尋英文「order」（大小寫混合測試）→ 找到
- [ ] 多關鍵字「王小明 訂單編號」（空白分隔）→ 只出現同時包含兩者的信（AND）
- [ ] 資料夾過濾：選「收件匣」→ 只出現收件匣結果；「寄件匣」→ 只出現寄件匣
- [ ] 日期範圍過濾 → 只出現該期間的信
- [ ] 寄件者過濾 → 只出現該寄件者的信
- [ ] 雙擊結果列 → **Outlook 開啟該封郵件原件**（非新視窗副本，資料夾位置正確）
- [ ] Outlook 關閉狀態下搜尋 → 仍可搜尋（索引已持久化）；此時雙擊結果 → 工具自動啟動 Outlook 並開啟

## 5. 外掛 PST 模式

- [ ] 切換「外掛 PST」→ 按「瀏覽…」→ 選取含測試 .pst 的目錄
- [ ] 勾選要掛載的 .pst → 確認訊息顯示 → 掛載後出現在來源清單
- [ ] 勾選該存放區、選資料夾、建立索引、搜尋、雙擊開啟 → 全部正常
- [ ] 掛載後 Outlook 資料夾清單可看到該 PST（如不想要，可於 Outlook「檔案 → 資料檔管理」移除）

## 6. 取消與穩定性

- [ ] 索引進行中按「取消」→ 狀態顯示已取消，程式無當機；重跑正常
- [ ] 索引中關閉程式 → 程式正常結束（下次重跑可補齊）
- [ ] 連續搜尋／排序多次，程式穩定無逾時
